## 4. main 통합 방법 제안 (팀 합의 필요)

PR은 "이 브랜치의 변경을 main에 합쳐 달라"는 요청입니다. 합치기 전에 팀원이 검토합니다.
**ROS 2에서 모든 패키지를 함께 빌드하려면 하나의 브랜치(main)에 하나의 `ros2_ws/src`로 모아야 합니다.**

1. 동한 님 브랜치: `pac-mission1-shared/` 하위 폴더를 루트로 올리고(`git mv`), 개인 파일을 이름 붙은 폴더로 옮깁니다(`config/donghan/` 또는 `config/planning.yaml`, `tests/donghan/`, `docs/donghan/`, `reports/donghan/`).
   공통 문서(`common_development_standard.md`, `integration.md`)는 루트 `docs/`에 둡니다.
2. `pac_common` 담당인 동한 님 브랜치를 main에 먼저 합칩니다.
3. 재성 님 제너레이터 커밋을 그 위에 다시 올립니다(`tools/`만 남음). 이어서 시뮬레이터를 합칩니다.
4. 태현 브랜치를 합칩니다. `team_paths.py`가 루트 배치를 자동으로 먼저 찾으므로 코드 수정은 필요 없습니다.
5. 루트 `pyproject.toml`(또는 패키지별 설정)이 모든 패키지와 테스트 폴더를 포함하게 하고, `colcon build`와 전체 테스트를 한 번에 돌리는 CI를 둡니다.

## 5. 팀 차원에서 더 정해야 할 것

1. **6단계 담당**: HDR50-22 URDF/MoveIt 2, 그리퍼(EOAT) 모델, 가반하중(50 kg)·접근 자세·충돌 검사. 미션 필수 항목인데 담당자가 없습니다.
2. **ROS 2 런타임**: 노드 구성, 메시지/서비스 정의, launch. 4 → 5 → 6 → 7 → 8 호출 순서와 State Manager.
3. **1~3단계와 7단계**: 실제 센서를 쓰지 않더라도 시뮬레이터 기반 대체 구현(측정 노이즈, 파손 판정, MISSING, 사후 heightmap 비교)이 있어야 "이상 박스 예외처리"와 "부분 재계획"을 시연할 수 있습니다.
4. **공통 어댑터**: pallet 모서리 좌표 ↔ 시뮬레이터 중심 좌표, 생성기 출력 → `SystemState`/`PlanningContext`. 지금은 사용하는 쪽마다 따로 구현합니다.
5. **3D 패턴 재생**: 저장된 계획/결과를 뷰어로 재생·비교하는 기능 (미션: 조건별 결과 비교, 3D 시각화).
